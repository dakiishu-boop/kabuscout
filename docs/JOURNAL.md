# 研究ジャーナル

反省と情報収集のループの記録。新しいセッション（人でもAIでも）は、まずここを読んでから続きを行う。
各ラウンド: 何を試したか → 結果（数字） → 反省 → 次に取り込む情報の候補。

## ラウンド0（2026-10-21〜22）: 土台づくり

- 値動きのみの9戦略・トリプルバリア（+2ATR/−1ATR/10日）・25年分（2002〜）
- **結果**: コスト0.2%/往復を引くと全戦略が平均マイナス（−0.1〜−0.5%/回）。コスト控除前でほぼゼロ
- 研究ループ（金庫・年ごと安定性・Bonferroni・危機の特例扱い）は改善を一切採用せず（偶然の範囲）
- 売買ルール研究: 現行は1枠あたり年率 −14%。利確を広く/長く持つほど改善（+6〜8ATR・30〜40日で +2%前後）。
  統計基準は通過したが金庫期間（直近半年）で現行に負け → 不採用
- 過去ペーパートレード（ウォークフォワード, 2008〜）: AI 年率 −1〜+2% ／ ランダム −11% ／ 日経平均 +8%
- **反省**: チャートだけでは手がかりが乏しい。コストが最大の敵。新しい種類の情報が必要
- **データの落とし穴**: Yahoo の TOPIX連動ETF(1306)は2009年〜しか無く、2015年の分割が未調整 → 日経平均に変更。
  深夜帯は当日分が一部銘柄しか無い → 8割以上揃った日だけ使う

## ラウンド1（2026-10-22）: 決算情報 ＋ 需給データ

- **調査**: JPX の銘柄別信用残（日々PDF）は直近5日分、空売り残高報告は直近2週間分しかサイトに無い → 過去検証は不可。
  毎日収集して蓄積開始（候補の参考表示のみ、約1年たまったら検証）
- Yahoo の決算（発表日・EPS予想/実績・サプライズ率）は2004年〜。ただしアナリスト予想のある約1,100銘柄（全体の約1/4）のみ
- **結果**:
  - 決算への市場の反応（発表前日→翌日の市場比騰落）が強いほど、その後10日の成績が単調に良い（−5%以下: +0.02% → +10%超: +0.47%、コスト前）
  - 新戦略「決算好反応」: 10日ルールでは1回あたり +0.15%（コスト後）、他戦略の中で最良
  - **長く持つと明確にプラス**: 期限のみ20日で +1.15%/回、40日で +2.0%/回、1枠あたり年率 +12%、77%の年でプラス
  - ただし日経平均比では +0.15〜0.17%/回（20日保有で78%の年に市場超え）。ランダム選定は日経平均比 −0.56〜−0.81% → 選定の効果は明確だが、絶対リターンの大半は相場全体の上昇
  - 決算特徴量をAIに入れても順位付けは改善せず（AUC +0.003、上位の期待値は低下）→ 今は「戦略（網）」として使う方が有効
  - 研究ループの正式判定では、決算好反応の条件調整も売買ルール変更も不採用（偶然の範囲 / 金庫で負け）
- **反省**: 「何を拾うか」より「どれだけ持つか」が戦略ごとに違う → 戦略ごとの売買ルールを研究できるようにした。
  ただし決算好反応×長期保有は、私（Claude）が全期間を見て見つけた仮説なので金庫は一部汚れている。本当の試験は今後の本番ペーパートレード
- **注意**: 現存銘柄のみ（生存者バイアス）。ランダム比較は同じ母集団なので相対比較はある程度公平

## ラウンド3（2026-10-22）: 配当

- Yahoo の株価ダウンロードに actions=True を付けるだけで、2002年〜全銘柄の配当（権利落ち日・1株配当）が取れる
- 特徴量: 配当利回り（年間の支払回数ぶんの直近合計 ÷ 株価）・増配率・次の権利落ち日までの営業日数
  - **落とし穴1**: 日数の窓（250営業日/360暦日）で年間配当を集計すると、権利落ち日が年ごとに数日ずれて抜け・二重計上が起きる → 「回数」で数える方式に
  - **落とし穴2**: 次の権利落ち日を「1年前＋250営業日」で推定すると日本の年間営業日（約245日）とずれて約5日遅れ、権利落ちをまたいで配当分の下落を拾っていた → 暦の上で1年後に修正
- 診断（修正後・配当受取は含めない保守的な計算）: 利回り3%以上を権利落ちの20〜40営業日前に買い、権利付き最終日に売る → 日経平均比 +1.1〜1.3%/回（62〜71%の年でプラス）。
  3週間前を切ってからでは効果なし。利回りが高いほどリターンも高い傾向（4〜6%は無配より20日で約+0.9%）
- 新戦略「権利取り」（既定: 利回り3%以上・権利落ちの21〜40営業日前）。※この範囲は私が全期間の診断を見て決めたので、金庫は一部汚れている

## ラウンド2・3の正式評価（研究ループ・金庫つき、1回だけ実行）

- 戦略の条件の調整: 13戦略すべて「偶然の範囲」で不採用
- **戦略ごとの売買ルール: 初めて採用が出た（3戦略）**
  - 決算好反応: 利確+6ATR/損切−3ATR/最長20日 … 1枠あたり年率の中央値 −9.9% → **+11.5%**（82%の年でプラス）、金庫 −14.1% → −8.9%
  - 52週高値ブレイク: +6/−2/30日 … −30.5% → −1.9%、金庫 −36.7% → −21.9%
  - スクイーズ: +8/−0.75/15日 … −7.3% → −0.1%、金庫 −35.3% → −30.7%
  - 惜しくも不採用: 権利取り（t=3.47 < 3.57）、押し目25日（3.31）、ボックス上抜け（3.06）。いずれも「長めに持つ」方向
- 過去ペーパートレード（ウォークフォワード, 2008〜）: 研究直後の計算は AI +3.4% と出たが、**採用前の設定で計算していたバグ**だった。
  採用した戦略ごとの売買ルールで計算し直すと **AI 年率 +11.1%（初めて日経平均 +8.2% を上回る）／ ランダム −4.5%**。最大下落 −46%
  - ただし戦略ごとの売買ルールは2008〜2026年4月のデータ全体を見て選んだので、過去ペーパートレードの大半の年は「選んだ期間の中」。実際より良く見えやすい（生存者バイアスも）
  - 直近（金庫期間）は −4.1% と日経平均を下回っている → 本当の実力は今後の本番ペーパートレードで確認する

## ラウンド4（2026-10-22）: 地合いによる買い控え（追加データなし）

- 仮説: 過去の大きな損失は相場全体の下落局面に集中しているので、日経平均が弱いときは新規の買いを控えれば改善するのでは
- 5通り（75日線割れで停止/1銘柄、75日線−5%割れで停止、20日−5%下落中は停止、危機局面は停止）をポートフォリオ全体の年ごとの成績で比較
- **結果: どれも改善せず不採用**（例: 75日線割れで停止 → 年率 +11.7% → +3.0%）。下げの後の反発局面まで逃してしまう。
  「75日線−5%割れで停止」だけはプラスの年の割合が 63% → 74% に増え最大下落も −46% → −42% に縮むが、年率は下がる（t=−0.8）
- **反省**: 地合いで売買を止める（マーケットタイミング）は、過去25年では割に合わなかった。危機局面で新規を1銘柄に絞る現行ルール程度に留める
- 金庫期間（2026年4月〜10月）はどの戦略・ルールでもマイナス → 直近は厳しい相場。採用した改善は金庫でも現行より良かった
- **反省**:
  - 情報を足す（決算・開示・配当）より、「戦略ごとに持つ期間を変える」ことの効果が大きかった。コストに勝つには売買回数を減らし、値動きが続く期間を持つことが重要
  - それでも指数（日経平均）に届かず、ぶれも大きい。指数を上回るには、銘柄選びの精度（AI）と、相場全体の下落局面を避ける工夫（地合いによる買い控え）が次の課題
  - 研究ループの合格ライン（Bonferroni）は試行を重ねるほど厳しくなる。今後は「試す前に仮説を絞る」ことが大事

## ラウンド5（2026-10-22）: AIの学習目標を実際の売買ルールに合わせる試み（追加データなし）

- 仮説: 3戦略は長めのルールで売買するようになったのに、AIは共通の短期ルール（+2/−1ATR・10日）の成否を学習している。実際のルールの結果で学習させれば順位付けが良くなるのでは
- 過去ペーパートレード（ウォークフォワード）で比較:
  - 共通の短期ルールで学習（現行）: **AI +11.1%** ／ ランダム −4.5%
  - 戦略ごとのルールの「利確に届いたか」で学習: AI −4.9%（ランダムと同じ。優位性が消えた）
  - 全シグナル共通で「コスト控除後に儲かったか」で学習: AI +5.2%、最大下落 −65%
- **結果: 現行のまま**。遠い利確ライン（+6〜8ATR）は儲かった取引でも届かないことが多く、AIが最良の戦略（決算好反応）を低く評価してしまった
- **反省**: AIには「全シグナル共通の物差し」で短期の質を学ばせ、どれだけ持つかは戦略ごとのルールで決める、という役割分担がうまくいく

## ラウンド6（2026-10-22）: 同時保有数・1日の新規数（追加データなし）

- 15通り（同時3/5/8/10/15銘柄 × 1日1/2/3銘柄）を過去ペーパートレード全体の年ごとの成績で比較 → **統計的に有意な改善なし・現行のまま**
- ただしリスクとリターンの関係ははっきりしている:
  - 集中（同時3銘柄）: 年率 +14〜15%、最大下落 −46〜48%、直近（金庫）−8.4%
  - 現行（同時5・1日2）: 年率 +11.7%、最大下落 −46%
  - 分散（同時15銘柄）: 年率 +8.2%（≒日経平均）、**最大下落 −31%、プラスの年 79%**
  - 1日1銘柄に絞るとどの組み合わせでも悪化（AIの上位が毎日入れ替わるので、買える数が少ないと良い候補を逃す）
- **反省**: これは「統計」より「どこまでリスクを取るか」の選択。ユーザーの好みで決めるべき（研究ループは年率だけで判定している）
