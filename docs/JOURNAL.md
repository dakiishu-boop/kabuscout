# 研究ジャーナル

各ラウンド: 何を試したか → 結果（数字） → 反省 → 次に取り込む情報の候補。

## ラウンド0（2026-10-21〜22）: 土台づくり

- 値動きのみの9戦略・トリプルバリア（+2ATR/−1ATR/10日）・25年分（2002〜）
- **結果**: コスト0.2%/往復を引くと全戦略が平均マイナス（−0.1〜−0.5%/回）。コスト控除前でほぼゼロ
- 研究ループ（金庫・年ごと安定性・Bonferroni・危機の特例扱い）は改善を一切採用せず（偶然の範囲）
- 売買ルール研究: 現行は1枠あたり年率 −14%。利確を広く/長く持つほど改善（+6〜8ATR・30〜40日で +2%前後）。
  統計基準は通過したが金庫期間（直近半年）で現行に負け → 不採用
- 過去ペーパートレード（ウォークフォワード, 2008〜）: AI 年率 −1〜+2% ／ ランダム −11% ／ 日経平均 +8%
- **反省**: チャートだけでは手がかりが乏しい。コストが最大の敵。新しい種類の情報が必要
- **データの落とし穴**: Yahoo の TOPIX連動ETF(1306)は2009年〜しか無く、2015年の分割が未調整 → 日経平均に変更。
  深夜帯は当日分が一部銘柄しか無い → 8割以上揃った日だけ使う

## ラウンド1（2026-10-22）: 決算情報 ＋ 需給データ

- **調査**: JPX の銘柄別信用残（日々PDF）は直近5日分、空売り残高報告は直近2週間分しかサイトに無い → 過去検証は不可。
  毎日収集して蓄積開始（候補の参考表示のみ、約1年たまったら検証）
- Yahoo の決算（発表日・EPS予想/実績・サプライズ率）は2004年〜。ただしアナリスト予想のある約1,100銘柄（全体の約1/4）のみ
- **結果**:
  - 決算への市場の反応（発表前日→翌日の市場比騰落）が強いほど、その後10日の成績が単調に良い（−5%以下: +0.02% → +10%超: +0.47%、コスト前）
  - 新戦略「決算好反応」: 10日ルールでは1回あたり +0.15%（コスト後）、他戦略の中で最良
  - **長く持つと明確にプラス**: 期限のみ20日で +1.15%/回、40日で +2.0%/回、1枠あたり年率 +12%、77%の年でプラス
  - ただし日経平均比では +0.15〜0.17%/回（20日保有で78%の年に市場超え）。ランダム選定は日経平均比 −0.56〜−0.81% → 選定の効果は明確だが、絶対リターンの大半は相場全体の上昇
  - 決算特徴量をAIに入れても順位付けは改善せず（AUC +0.003、上位の期待値は低下）→ 今は「戦略（網）」として使う方が有効
  - 研究ループの正式判定では、決算好反応の条件調整も売買ルール変更も不採用（偶然の範囲 / 金庫で負け）
- **反省**: 「何を拾うか」より「どれだけ持つか」が戦略ごとに違う → 戦略ごとの売買ルールを研究できるようにした。
  ただし決算好反応×長期保有は、私（Claude）が全期間を見て見つけた仮説なので金庫は一部汚れている。本当の試験は今後の本番ペーパートレード
- **注意**: 現存銘柄のみ（生存者バイアス）。ランダム比較は同じ母集団なので相対比較はある程度公平

## 次に取り込む候補（優先順・理由つき）

1. **EDINET API（金融庁・無料・要APIキー＝ユーザー登録が必要）**: 有報/四半期の財務 → PBR・PER・ROE・増収率などのバリュー/クオリティ。
   東証のPBR改善要請（2023〜）以降、低PBR是正が大きなテーマ。XBRLの名寄せが重い
2. **配当・株式分割の履歴（Yahoo, 無料, 長期）**: 配当利回り、権利付き最終日前後の値動き（3月・9月の権利取り）
3. **J-Quants（JPX公式）**: 無料プランは過去2年・12週遅延（研究用には使えるが本番には不可）。有料プランなら決算・信用残・投資部門別が揃う
4. **投資部門別売買動向（JPX, 週次・市場全体, 過去分あり）**: 海外投資家の売買 → 地合い判定の補強
5. 信用残・空売り残高は蓄積中（約250日分で検証開始。2027年秋ごろ）
