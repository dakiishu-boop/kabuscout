# 研究の採用・打ち切りのルール（2026-11-28 から。ジャーナル §101）

同じ過去のデータで案を足し続けると、たまたま良い案を拾うだけになる。試した数はすでに数百通りある。
このルールは、日本株（kabuscout）・autotrade・USScout のすべての研究に当てはめる。

## 1. 採用は、試す前に書いた基準を満たしたときだけ
- 試す前に、ジャーナルへ次のことを書いてコミットする（コミットの日時が証拠）。
  - 比べる相手
  - 期間（2019年以降を必ず含む）
  - コスト
  - 乱数の種の数
  - 合格の基準（t 値や、すべての行で上回るかなど）
- 結果を見てから基準・期間・指標を変えない。変えたら、それは新しい試みとして数える。
- 「例外として採用」はしない。基準に届かなかった案（t=1.49 など）は、比較用の口座（前向きの記録）に回す。

## 2. リスクの好みは「研究の採用」ではなく、ユーザーの選択として分けて書く
- 年率と下落の深さの交換（投資量を増やす、損切をゆるめるなど）は、腕が上がったわけではない。
  ユーザーが明示的に選んだときだけ入れ、ジャーナルには「ユーザーのリスクの選択」と書く。
- その際は次の3つを並べて記録する。
  - 最大下落（最悪の種）
  - 最悪の年
  - 止める目安
- これまでの例:
  - §45（弱い相場だけ合意モード、t=1.49、下落を抑える側）
  - §91（autotrade の「弱い相場でも減らさない」、下落を深くする側）
- 実際のお金に移す前に、どちらの方向で行くかをユーザーと一本化する（下の 4）。

## 3. 打ち切り
- 1つの話題で、事前に決めた試みが続けて不合格になったら、その話題の過去データでの探索は止める。
  その後は前向きの記録（影・比較用の口座・ペーパートレード）だけで決める（§91・§94〜§98 と同じ扱い）。
- 口座全体の年率の差は、種のぶれ（±3〜4ポイント、§80）に埋もれる。物差しの較正（§72 の 6）が済むまでは、次の2つだけを採用の根拠にしない。
  - 1つの種の口座の年率
  - 種1つずつの t 値
  - 根拠には、複数の種の平均、または候補ごとの指標（順位相関・上位の1回平均）を使う。

## 4. 実際のお金に移す前の条件（研究ではなく運用の前提）
- リスクの方針が、kabuscout と autotrade で一本化されていること（2 を参照）。
- 毎日の実行が、引け後〜翌朝の寄付前に確実に動くこと。
  - GitHub の定時実行は約10時間遅れたり、起動しなかったりする（§92・§99・§100）。
  - autotrade は、約定が1日遅れると 2019年以降の年率が +18.7% → +9.1% に下がる。
- 比べる基準は 2019年以降で、コスト0.5%の場合も示すこと。
